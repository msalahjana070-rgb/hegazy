# تطبيق إنشاء تقرير

تطبيق ويب أوفلاين (PWA) لإعداد التقارير وإرسالها مباشرةً عبر واتساب أو نسخها، مع خيارات تغيير الألوان وأحجام الخطوط وتعديل القوائم.

**إعداد محمد صلاح — M.S.AI**

## خطوات الرفع على GitHub Pages
1. ارفع جميع الملفات السبعة إلى المستودع (Repository) على GitHub.
2. افتح **Settings** ثم **Pages** واختر Branch: `main` والمجلد `/ (root)` ثم اضغط **Save**.
3. افتح الرابط في **Google Chrome** على الهاتف واضغط **«تثبيت التطبيق»**.
